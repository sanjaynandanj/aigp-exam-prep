# The Study System: Active Recall, Spaced Repetition, the Question Journal

**Phase 0 · Lesson 03 · ~1h · BoK Domain —**

## EXAM FOCUS

No BoK mapping — this is the operating system the rest of the course runs on. The AIGP rewards two things: precise recall of dense frameworks (AI Act tiers, NIST functions) and pattern-matching scenarios to the right rule. Both are trained by testing yourself, not by re-reading. Set this system up before Phase 1.

## CORE

### Principle 1 — Book the exam first

Before Week 1, book a real exam date (see Lesson 01 for how). A fixed date:

- converts "someday" studying into a backward-planned schedule,
- forces a track choice (4 / 8 / 12 weeks — see ROADMAP.md),
- makes every skipped session visibly expensive.

If you cannot commit money yet, at minimum write a date in your calendar and treat it as booked. But paid beats penciled.

### Principle 2 — Active recall over re-reading

Re-reading produces familiarity ("I've seen this") which masquerades as knowledge ("I can produce this"). The exam tests production. So:

| Instead of… | Do… |
|---|---|
| Re-reading a lesson | Closing it and writing its MEMORY HOOKS facts from memory |
| Highlighting | Turning the highlight into a question card ("What are the four NIST RMF functions?") |
| Watching/reading passively | Answering the SELF-CHECK before peeking, every lesson, every time |
| "Reviewing" the AI Act | Reciting the prohibited practices list blind, then checking |

Every lesson in this repo ends with SELF-CHECK questions specifically so recall is built in. Do them honestly — answers covered, written or spoken out loud.

### Principle 3 — Spaced repetition: the +2 / +7 rule

Memory decays on a curve; re-testing just before you forget flattens it. The lightweight protocol used throughout this course:

1. **Day 0:** learn the lesson, do the SELF-CHECK. Anything missed goes in the question journal.
2. **Day +2:** re-test only the missed items. Still wrong → stays in the journal.
3. **Day +7:** re-test again. Right twice in a row → retire the item.

No flashcard app required (though Anki works fine if you prefer). A markdown file and a calendar are enough.

### Principle 4 — The question journal

Every practice question you get wrong — baseline, quizzes, mock — earns a row in the journal. Use **`practice/question-journal-template.md`** in this repo. Per entry, capture:

| Field | Why |
|---|---|
| Question topic + source | So you can re-find and re-test it |
| Your wrong answer | Wrong answers repeat; name yours |
| The correct answer + one-line why | The rule, not the letter |
| **Error type** | *Knowledge gap* (didn't know) vs *misread* (knew, but rushed the stem) vs *distractor bite* (two answers looked right) |
| Re-test dates | +2 and +7 day checkboxes |

The error-type column matters most: knowledge gaps send you back to a lesson; misreads and distractor bites send you to Phase 7 (question technique). Fixing the wrong problem wastes weeks.

### Principle 5 — One-page phase summaries

At the end of each phase, before starting the next: write a **one-page summary of the phase from memory**, then check it against the lessons' MEMORY HOOKS sections and patch the gaps in a different color. These eight pages become your final-week review pack — by exam week you review 8 pages, not 72 lessons.

### The weekly rhythm

| Day | Activity |
|---|---|
| Study days (3–5×/wk) | New lessons + their SELF-CHECKs |
| Every session start | 5 minutes: journal items due at +2/+7 |
| End of each phase | One-page summary from memory + domain quiz (Phase 7 quizzes) |
| Final week | 8 one-pagers + question journal + second AI Act pass + full mock |

## CASES & EXAMPLES

1. **The re-reader.** A candidate reads all 72 lessons twice, feels fluent, and scores 265. Post-mortem: they had never once retrieved the Annex III categories without the page open. Familiarity ≠ recall. The fix cost nothing — the SELF-CHECKs were already there, unused.

2. **The journal diagnosis.** After the Domain II quiz, a candidate's journal shows 7 misses: 2 knowledge gaps, 5 "distractor bites" where they picked the *plausible* answer over the *precise* one. Correct fix: not more AI Act study — Phase 7 Lesson 01 (distractor patterns) plus slowing down on stems.

3. **The +2/+7 payoff.** A candidate misses "difference between HITL and HOTL" on Day 0, re-tests Day 2 (wrong again — back in journal), Day 4, Day 9 (right twice, retired). On the real exam a scenario hinges on exactly that distinction. Two total minutes of re-testing bought a scored point.

## MEMORY HOOKS

**"B-R-S-J-S":** **B**ook the exam → **R**ecall actively → **S**pace it (+2/+7) → **J**ournal every miss → **S**ummarize each phase on one page.

The 5 facts to retain:

1. Book the exam before Week 1 — a fixed date is the highest-leverage study decision.
2. Test yourself instead of re-reading; do every SELF-CHECK covered-answer first.
3. Missed items get re-tested at +2 and +7 days; retired after two consecutive correct answers.
4. Every wrong practice question goes in the question journal *with an error type* (gap / misread / distractor).
5. End each phase with a one-page summary from memory; those 8 pages are your final-week review.
